### æverything — WordPress theme

The same design rebuilt as a real WooCommerce theme, so the client runs the
store themselves from wp-admin.

- **[`aeverything-theme.zip`](aeverything-theme.zip)** — install via
  *Appearance → Themes → Add New → Upload Theme*
- **[`aeverything-wordpress-theme/`](aeverything-wordpress-theme/)** — the source

**Requires:** WordPress 6.4+, PHP 8.0+, WooCommerce.

**What the client edits without code**

| In wp-admin | Controls |
|---|---|
| Products | The shop and product pages |
| Posts | Æ Magazine articles |
| Æ Gallery | Gallery artwork |
| Æ Education | Lessons, topics, resources |
| Æ Programs | Mentorship and Fitness cards |
| Video Briefs | Incoming AI-video requests + customer files |
| Appearance → Customize | Hero images, headlines, countdown, colours, socials |

**Note:** GitHub can host this code but cannot run it — WordPress needs PHP
hosting. Use the live design preview above for review; install the theme on a
WordPress host to see the working store.
